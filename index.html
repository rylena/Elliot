Meet Elliot

AI-Powered Linux Command Companion

About Elliot

Elliot is an AI assistant that acts as a bridge between natural language and Linux terminal commands. Describe what you want in plain English and Elliot generates the correct command and can execute it through a simple web interface.


Built to make the command line easier and more intuitive, Elliot focuses on safe, practical commands and concise explanations, so you can move faster without memorizing flags and long incantations.

Elliot turns plain English into Linux commands and runs them for you via the web UI.

Technologies

Python

Server and terminal orchestration using Flask and PTY.

Gemini API

LLM-powered understanding of natural language requests.

WebSockets

Real-time streaming between the browser and terminal backend.

Terminal Backend

Interactive Bash session with live output rendering.

Features

Natural Language to Command

Documentation

Getting Started

Download the latest Elliot release and run it locally. Get it from the Releases page:

# 1) Download the latest release archive (zip or tar.gz) from the link above
# 2) Extract the archive, then go into the project folder
cd Elliot

# 3) Make the run script executable
chmod +x ./run.sh

# 4) Start the application
./run.sh

Basic Usage

After the server starts, open the web UI. Ask in natural language or be explicit. Elliot will propose and run the right command, streaming output live.

// Examples:
"List files in this folder"
"Show disk usage for /var, human readable"
"Find all .py files modified today"
"Create a new folder named logs"

Example Requests

Try these to see how Elliot translates natural language to commands:

"What is my current directory?" Outputs the absolute path (pwd)
"Search recursively for TODO in this project" Uses ripgrep/grep to find matches
"Show top 10 largest files here" Uses du/sort/head with human-readable sizes
"Install requests with pip" Installs the Python package safely
