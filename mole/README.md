# Mole - Google Meet Pre-join Screen Recreation

This project recreates the Google Meet pre-join screen design exactly as shown in the reference image.

## Features

- **Exact Visual Recreation**: Matches the Google Meet pre-join screen design pixel-perfectly
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Interactive Elements**: 
  - Name input with character counter (0/60)
  - Join button that enables when name is entered
  - "Other ways to join" dropdown
- **Accessibility**: Full keyboard navigation and screen reader support
- **Modern Styling**: Uses Google Sans font and Google's design system colors

## Files

- `index.html` - Main HTML structure
- `style.css` - Complete styling to match Google Meet design
- `script.js` - Interactive functionality and accessibility features
- `README.md` - This documentation

## How to Use

1. Open `index.html` in a web browser
2. Enter your name in the input field
3. Click "Ask to join" when ready
4. Explore the "Other ways to join" option

## Design Details

The recreation includes:
- Google Meet logo with colored squares
- "Sign in" link in header
- Large video preview area with "No camera found" message
- Name input with 60-character limit and counter
- Disabled join button that enables when name is entered
- Footer with Terms of Service and Privacy Policy links
- Exact color scheme matching Google's design system

## Browser Compatibility

Works in all modern browsers including:
- Chrome
- Firefox
- Safari
- Edge

## Notes

This is a visual recreation for demonstration purposes. In a real implementation, you would need to integrate with actual video conferencing APIs and camera access.
